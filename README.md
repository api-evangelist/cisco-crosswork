Cisco Crosswork is Cisco's service-provider network automation portfolio — Crosswork Network Controller, Data Gateway, Zero Touch Provisioning, Optimization Engine, Network Change Automation and Crosswork Workflow Manager. Unusually for Cisco, the specifications are published openly: the CiscoDevNet/crosswork-openapi-spec repository carries more than a hundred Swagger documents across the CNC, CDG, ZTP, COE and NCAHI components and multiple product versions, including IETF L2VPN/L3VPN and traffic-engineering service models, and Cisco publishes a further 90-operation Swagger contract for Crosswork Workflow Manager 2.1 behind its DevNet reference renderer. That CWM contract includes a first-party Model Context Protocol endpoint. Crosswork is customer-deployed software: every base URL is a path on a host the operator installs, and there is no Cisco-hosted endpoint, no published price and no rate limit.

**Areas:** Network Automation · Service Providers · Orchestration · Networking · Assurance · Telecommunications · RESTCONF · YANG · Zero Touch Provisioning · Workflow Automation · Traffic Engineering · MCP

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Cisco Crosswork: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
